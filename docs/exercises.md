# 演習

## 1. 指示を比較する

`AGENTS.md` と Copilot 指示から、共通ルール2つと片方だけのルール2つを根拠付きで挙げます。

## 2. Skill を使う

```text
$plan-learning-task を使い、タスクへタグを追加して
list --tag NAME で絞るための計画を作ってください。
```

計画にスキーマ互換性、CLI、テスト、文書が含まれれば完了です。

## 3. 小さな実装

`list` の表示順を検討し、現在の順序をテストで固定してから変更の互換性を説明します。

## 4. レビューを委譲する

`subagents/roles/reviewer.md` で読み取り専用レビューを依頼し、指摘を採用・保留・却下に分類します。

## 総合課題

タスクへ任意の `due` 日付（`YYYY-MM-DD`）を追加し、CLI で設定・表示する計画を作ります。実装は任意です。

制約:

- 既存 JSON を読める。
- 不正な日付を拒否する。
- 標準ライブラリだけを使う。
- 既存テストを壊さない。

planner で仕様を固めて親が承認し、tester で境界値を整理し、完成後に reviewer で確認します。
