# サブエージェント学習ガイド

サブエージェントは、境界が明確な仕事を独立した文脈で進める手段です。親は最終判断と統合責任を持ちます。

## 向く仕事

- 読み取り専用の調査
- 独立した複数案の比較
- 変更後のレビューやテスト観点
- ファイル領域が重ならない実装

## 向かない仕事

- 1関数を細切れにした同時編集
- 要件未確定で別々の前提を置きそうな仕事
- 本番操作、削除、送信など親が許可を判断すべき仕事
- 説明・統合コストの方が大きい小さな仕事

## 流れ

```text
利用者の目的
    ↓
親: 制約と依存関係
    ├─ 調査担当（読み取り）─┐
    ├─ テスト担当（観点）──┼→ 親: 根拠確認・統合・最終検証
    └─ 実装担当（限定範囲）─┘
```

## 委譲テンプレート

```text
目的:
  learning_tasks/core.py の既存仕様を調査する。
対象:
  core.py と test_core.py の読み取りのみ。
しないこと:
  編集、外部アクセス、仕様の推測。
返却形式:
  現在の振る舞い、根拠、未確定事項。
完了条件:
  add / list / complete の正常系と主要エラーを説明できる。
```

`subagents/roles/` は自動起動設定ではなく、利用中の機能へ渡すプロンプト例です。

## 親の統合チェック

1. 出力が依頼範囲内か。
2. ファイル、テスト、ログの根拠があるか。
3. 担当間の前提が衝突していないか。
4. 同じファイルの変更が競合していないか。
5. 親が最終テストを実行したか。
