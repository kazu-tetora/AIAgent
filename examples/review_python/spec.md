# タスク絞り込みの仕様

`select_tasks(tasks, *, done=False, limit=10)` をレビューする。

- 入力は `id: int`、`title: str`、`done: bool` を持つ辞書のリスト。IDは一意とする。
- `done` が指定値と一致するタスクをIDの昇順で返す。
- `limit` は整数。最大 `limit` 件を返し、0なら空リスト、負なら `ValueError`。
- 入力が空、または一致するタスクがない場合は空リスト。
- 入力リストの順序と辞書の内容を変更しない。
- 返却するリストは新しくする。要素の辞書は入力と共有してよい。
- 上記の型・フィールドを満たさない入力の扱いは、この教材の対象外。

レビュー演習では、この仕様と `buggy.py` のみを対象とする。答え合わせはレビュー後に行う。
