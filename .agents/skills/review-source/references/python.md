# Pythonの観点

- `None`、空コンテナ、`0`、`False` の区別が仕様に合うか。
- インデックス、スライス、`range` の端点と上限件数が合うか。
- `sort`、`pop`、辞書更新、浅いコピーが呼び出し元へ影響しないか。
- 可変のデフォルト引数や共有参照が呼び出し間で残らないか。
- 例外型と捕捉位置が適切か。CLIならstderrと終了コードも確認する。
- ファイルの文字コード、コンテキスト管理、保存失敗時の整合性を確認する。
- 型ヒントは実行時検証ではない。外部入力の検証と既存形式の互換性を確認する。

対象プロジェクトのPythonバージョンと既存テスト手順を優先する。このラボはPython 3.10以上・標準ライブラリのみ。再現に外部パッケージを必須にしない。
